(condicionales, funciones, bucles, colecciones y validación de datos).

| Archivo | Tema |

| 02 | Números únicos y análisis de una lista |
| 03 | Cálculo de salario con horas extra y antigüedad |
| 04 | Análisis de calificaciones con estadísticas |
| 05 | Precio final con descuentos por marca y por día |
